# 灵图助手 · 1.4.0

灵图助手通过本机 Codex 分析需求，使用灵图工具修图、生图和管理图库。生图仍使用你在「设置与备份」配置的服务及密钥。

## 开始使用

1. 安装 Codex CLI，并在当前 Windows 用户下运行 `codex login` 完成登录。软件会检测 PATH 或标准 npm 安装目录中的 Codex。
2. 打开灵图，点击左下角「AI 助手」。在连接设置或欢迎页点击「连接本机 Codex」。
3. 在图库勾选素材，右栏会显示引用数量。点击引用图可完整预览；附件按钮可先将本地图片导入图库并引用。
4. 描述目标，例如「把选中的照片换成森林背景，保留人物与服装，先试一张」。助手读取图片并创建逐项计划。
5. 核对数量、服务、指令和费用说明，点击「批准生成首张样图」。样图完成后点击预览；满意后批准剩余数量。
6. 结果自动作为新素材保存，原图保留。在「任务」页展开逐项结果，可标记待审核、保留或不采用。不采用不会删除文件。

费用未知时不会估造单价。Codex 对话与生图服务分别计费；本机 Codex 登录不替代 RunningHub 等服务的配置。

## 图库管理

可以让助手提出分类、标签、收藏、命名、回收站及新建分类计划。批准后执行；已完成的整理可撤销。有关字段如果后来被修改，撤销会提示冲突；有素材或子分类的新分类不能自动撤销。Agent 不提供永久删除工具。

## 技能

内置需求分析、批量修图、提示词优化、图库整理和批量生图规划。技能页可查看、编辑、启用、恢复内置版本，或导入 `SKILL.md`、目录及 ZIP。

导入的技能默认不启用。含脚本的包会标为不兼容，不执行脚本。技能按标准 YAML 头读取 `name`、`description`，技能名使用小写英文、数字和连字符。文本参考资源可由助手通过技能工具读取。

技能描述助手的工作步骤，与发送给生图端的提示词预设分别管理。修改和选择技能在下一条消息生效。

## 外部 MCP

在助手连接设置中点击「复制外部 MCP 配置」，粘贴到本机 MCP 客户端。源码运行通过 Python 模块启动；安装版通过附带的 `LingTu-MCP.exe` 启动。MCP 只转发到已运行的灵图，不独立打开图库或启动生图队列。

配置含本机连接令牌，请只用于本机客户端。灵图重启后令牌改变，需要重新复制。存在多个窗口时，外部助手需通过 `lingtu_state` 选择明确的窗口。外部 MCP 只能提出计划；到灵图「任务」页批准后才执行。

## 中断与恢复

生成任务与手动 AI 任务共享最多两个活动名额，额外任务排队。停止计划会停止后续提交；平台已收到的请求仍可能完成并计费。

重启后不会自动重新提交未确认的生成请求。任务页的「恢复查询 / 入库」会查询已保存的 RunningHub 任务 ID、恢复已有结果下载或入库。无法确认的平台请求需先核对平台记录，再决定是否创建新计划。

生图服务配置改变后，旧计划需要重新创建；恢复查询前需恢复原服务配置。完整备份包含助手计划、会话、技能和生图结果；恢复到新图库后需重新确认未开始的计划。

## 第一版范围

主要支持 Windows 本机桌面和本机浏览器。DeepSeek 内置执行器、远程网页连接电脑的桥接、完整无限画布、多用户 Agent、系统级操作和在线技能市场尚未提供。Codex 会话映射保存在图库，Codex 自身的历史由本机 Codex 管理。
