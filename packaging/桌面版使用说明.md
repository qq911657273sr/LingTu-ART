# 灵图 ART 桌面版

运行「LingTu-ART-Setup」安装程序，按向导安装。
安装后从桌面或开始菜单打开「灵图 ART」。应用使用独立窗口，关闭窗口即退出，无需保留命令行窗口。

若安装程序与旧版 config.json 位于同一文件夹，安装向导会提供「继续使用当前已有的素材库」选项；勾选后使用原素材目录，原文件不搬动。
需要改用其他库时，可进入「设置与备份」查看当前目录、备份或恢复素材库。

应用安装在当前用户的 LocalAppData/Programs/ARTSPACE。
应用配置、日志和窗口缓存保存在 LocalAppData/ARTSPACE；新建素材库默认保存在其中的 data 目录。
卸载会删除程序和快捷方式，保留素材与配置，重新安装后可继续使用。

安装包包含前端、Python 运行时及 FFmpeg/ffprobe，不需要另外安装 Python 或 Node.js。
如果机器缺少 WebView2，安装向导会调用微软官方安装程序联网补齐。
支持 Windows 10/11 64 位。
