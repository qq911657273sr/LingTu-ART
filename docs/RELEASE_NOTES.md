## 灵图 ART 1.4.1

本次加入应用内检查更新，并发布灵图助手首版。

### 更新功能

- 在「设置与备份」顶部显示当前版本，点击「检查更新」读取本仓库 GitHub 正式版。
- 支持查看中文更新说明、打开发布页面和下载 Windows 安装包。
- 网络不可用、GitHub 限流、安装包尚未准备好时显示明确提示。
- 程序与安装包从 version.ini 读取同一版本号。以后提升版本并同步 main 后，GitHub Actions 自动测试、构建、发布新版本及 SHA256 校验文件；已发布的相同版本不自动覆盖。

### 灵图助手

- 本机 Codex 对话、图片分析、逐项修图 / 生图计划，先生成一张样图，确认后批量处理。
- 分类、标签、收藏、命名与回收站整理计划；支持撤销并核对后来变更。
- 内置五项 Skill，支持查看、编辑、启用及 SKILL.md / ZIP / 目录导入。
- 共享 MCP 工具、持久化任务、生成结果审核及完整图片预览。

### 安装与使用

下载下方 `LingTu-ART-Setup-1.4.1.exe`。关闭旧版后安装，已有素材库和个人配置保留。

助手首次使用需安装并登录本机 Codex CLI。生图服务使用自己的 RunningHub、OpenAI 兼容接口或 Gemini 配置；素材、API 密钥不会随源码发布到 GitHub。

首版助手支持本机桌面 / 本机浏览器。DeepSeek 内置执行器与远程 Agent 桥接尚未提供。
